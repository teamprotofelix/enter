이용 방법 How to Play

처음 방문이라면 3단계로 시작하세요. 모든 게임은 별도 설치 없이 브라우저에서 바로 실행됩니다. New here? Follow three steps. Every game runs in your browser — no install needed.

STEP 01

게임 선택 Pick a game

게임 카드에서 장르·난이도·설명을 확인하고 클릭합니다. 고민되면 「무작위 선택」을 눌러보세요. Check genre, difficulty, and description on each card, then click. Undecided? Try random pick.

STEP 02

조작 확인 Check controls

각 게임 화면에 조작법이 안내되어 있습니다. 배틀최강전은 키보드, 심사기준 스트라이커는 방향키와 슛 버튼을 사용해요. Controls are shown in each game. Battle Supreme uses the keyboard; Striker uses arrows and the shoot button.

STEP 03

기록 도전 Chase the record

이기고 배우고 즐기세요! 지식은 실력이 되고, 실력은 기록이 됩니다. 새 게임도 계속 준비 중입니다. Win, learn, and have fun — knowledge becomes skill, skill becomes records. More games are on the way.
